# WEEK-3-FUNDAMENTOS-DE-PROGRAMACION-CON-PYTHON-JJBLL
Sistema de inventario desarrollado en Python como parte del módulo de Fundamentos de Programación. Permite gestionar productos mediante operaciones CRUD, además de calcular estadísticas y trabajar con archivos CSV. El proyecto aplica estructuras de control, funciones, listas, diccionarios y manejo de errores.
